refatoração dos projetos `node-express` e `ruby-sinatra`.

| ADR | Título | Status |
|-----|--------|--------|
| 0001 | Usar shared-configs como Git Submodule | Aceito |
| 0002 | Preservar diferenças de dialeto SQL no database.sql compartilhado | Aceito |

| 0004 | Criar repositório product para documentação centralizada | Aceito |

Cada ADR segue o formato: Status, Contexto, Decisão, Consequências e Relacionados.
